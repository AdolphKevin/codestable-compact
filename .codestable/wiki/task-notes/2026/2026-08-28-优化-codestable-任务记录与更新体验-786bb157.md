# 优化 CodeStable 任务记录与更新体验

## 请求

从根本上优化 CodeStable Skill，避免大型重构任务范围误报、历史知识使用版本被迫改写、任务删除路径误报、更新任务快照繁琐、学习命令输出过长和版本状态含义不清。

## 处理摘要

重构任务学习与漂移检查：任务记录使用代表性范围并识别 Git 已确认的删除和重命名，任务更新保留历史 knowledge_use revision；新增从现有任务生成更新快照的 template --task-id 和 learn --compact，并明确 doctor 的兼容版本漂移状态。同步 Skill 指南、发行文档、受管 Wiki 说明和回归测试。

## 最终结果

大型重构不再需要把 task-note 写成完整文件清单；已经记录的知识使用证据不会因卡片后续升级而改写；本次删除或重命名目标不会被误报为缺失路径，current 卡片引用仍继续审核。任务更新可由工具预填完整快照，学习输出可隐藏无操作价值的已验证引用明细。
