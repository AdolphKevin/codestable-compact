# upgrade 逐页证据聚合到单一任务记录

## 结论

一次 CodeStable upgrade 维护一条 knowledge-migration task-note，并在完整逐页账本中保存 legacy 哈希、备份、结论和证据；pending 页面保留且使升级保持 partial。

## 背景与理由

逐页审计是证据粒度，不应被实现成顶层任务粒度；聚合账本同时满足一项逻辑任务一条记录和逐页追溯。

## 影响

- 不得再为每个 covered、obsolete 或 migrated 页面创建普通 task-note
- partial migration 只可沉淀已逐项验证的 accepted/verified 结论
- pending 页面不得删除或被报告为迁移完成
