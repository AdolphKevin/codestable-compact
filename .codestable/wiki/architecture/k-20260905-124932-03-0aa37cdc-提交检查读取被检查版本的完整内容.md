# 提交检查读取被检查版本的完整内容

## 结论

drift --cached 与 audit --cached 从 Git 暂存区读取配置、知识正文和源码；--base 从 HEAD 读取被检查提交的内容。检查在内存中构建目录，其他未暂存修改不能使检查通过或失败。
