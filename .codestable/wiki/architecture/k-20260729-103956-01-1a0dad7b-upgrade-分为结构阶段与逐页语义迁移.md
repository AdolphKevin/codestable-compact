# upgrade 分为结构阶段与逐页语义迁移

## 结论

CodeStable upgrade 包含两个不可合并的阶段：bootstrap 只负责 manifest 管理文件刷新、旧知识逐页清单和逐页备份；$cs Agent 随后逐页对照当前实现、可执行测试与 current Wiki 完成语义审计。

## 背景与理由

历史页面可能重复、过时或与当前行为冲突，确定性脚本无法可靠判断哪些结论仍是真相，也不能把旧页批量照抄为当前卡片。

## 影响

- knowledge_migration.required 为 true 时，结构命令成功不等于 upgrade 完成
- 旧页只能作为审计线索，不能单独作为 verified 证据
- 每个旧页必须单独产生审计 task-note
