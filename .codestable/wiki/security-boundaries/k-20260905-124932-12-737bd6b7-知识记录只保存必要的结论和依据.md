# 知识记录只保存必要的结论和依据

## 结论

任务记录和卡片不得包含原始提示、模型完整响应、完整命令输出、完整差异、秘密或个人数据。默认学习入口会检查常见秘密格式并在写入前拒绝命中内容；其余内容仍需由执行 Agent 检查和压缩。
