# 接口

- 明确范围查询同时返回直接相关知识和声明适用的共享约束，弱文本扩展需显式指定；依赖只扩展一层当前卡片。
- 模板与结果默认精简，扩展卡片、更新记录和完整诊断使用对应参数。
- 同一具体范围内的不同卡片可以成对提示核对，最多五组；提示不判定语义冲突，也不改变检查结果。
- 任务文件查询列出关联知识及直接取代的旧卡片，仅作使用依据的卡片单独列出；提交前仍需核对文件差异。
