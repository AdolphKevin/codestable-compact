# 任务更新模板和紧凑学习输出保留完整控制信息

## 结论

template --task-id <T-...> 从当前 task-note 生成可编辑的完整更新快照，预填任务 ID、当前 revision、正文、范围、来源和历史 knowledge_use；归档任务会拒绝并指向 canonical 记录。learn --compact 保留计划令牌、应用候选、需要处理的引用、未验证引用和各类计数，只省略完整 verified 引用列表；不带该参数时继续返回完整 JSON。

## 背景

未单独记录；参见来源任务。

## 理由

任务更新不应要求调用者手工重建整份快照，也不应让成百上千条成功引用淹没真正需要处理的内容；同时必须保留计划令牌和诊断信息，不能以简化输出削弱安全控制。

## 影响

- 继续已有任务时应优先生成 template --task-id，再修改真实变化字段并完成 dry-run/token apply。
- 自动化需要完整引用明细时保持原命令不加 --compact；交互式 Agent 默认可使用紧凑模式。
- 新增 task-note 会把 kind 写入元数据，旧记录缺少该字段时更新模板使用无路由作用的 task 默认值。
